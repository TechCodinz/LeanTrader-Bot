## 🚀 DEPLOYMENT INSTRUCTIONS

### Step 1: VPS Setup
```bash
ssh ubuntu@your-vps-ip

# Install Python 3.11+
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip -y

# Create directory
mkdir -p ~/trading-bot
cd ~/trading-bot
```

### Step 2: Upload Files
```bash
# Upload all files to VPS
scp -r /workspace/* ubuntu@vps-ip:~/trading-bot/

# OR use git
git clone your-repo
cd your-repo
```

### Step 3: Install Dependencies
```bash
# Core packages (required)
pip3 install ccxt pandas numpy scikit-learn tensorflow

# Advanced packages (recommended)
pip3 install talib matplotlib qiskit catboost lightgbm xgboost

# AI/ML (optional but recommended)
pip3 install anthropic langchain

# Utilities
pip3 install networkx optuna beautifulsoup4 requests

# Communication (optional)
pip3 install python-telegram-bot
```

### Step 4: Configure
```bash
# Create .env file
nano .env

# Add your keys:
BYBIT_API_KEY=your_testnet_key
BYBIT_API_SECRET=your_testnet_secret
USE_TESTNET=true

# Optional:
ANTHROPIC_API_KEY=your_claude_key
TELEGRAM_BOT_TOKEN=your_bot_token
```

### Step 5: Run
```bash
# Test run
python3 COMPLETE_ULTIMATE_ORCHESTRATOR.py --mode testnet

# Production run with screen
screen -S trading-bot
python3 COMPLETE_ULTIMATE_ORCHESTRATOR.py --mode testnet
# Ctrl+A, D to detach

# Check it's running
screen -r trading-bot
```
