## 🛠️ VPS DEPLOYMENT STEPS

### Step 1: Prepare VPS
```bash
# SSH into VPS
ssh ubuntu@your-vps-ip

# Update system
sudo apt update && sudo apt upgrade -y

# Install Python 3.11+
sudo apt install python3 python3-pip -y

# Create directory
mkdir -p ~/trading-bot
cd ~/trading-bot
```

### Step 2: Upload Files
```bash
# Option A: Use SCP
scp -r /workspace/* ubuntu@your-vps-ip:~/trading-bot/

# Option B: Use Git
git clone your-repo
cd your-repo

# Option C: Manual upload via SFTP
# Use FileZilla or similar
```

### Step 3: Install Dependencies
```bash
# On VPS
cd ~/trading-bot

# Install core packages
pip3 install ccxt pandas numpy scikit-learn tensorflow anthropic langchain

# Install advanced packages
pip3 install talib matplotlib qiskit catboost lightgbm xgboost

# Install utilities
pip3 install networkx optuna stripe telegram python-telegram-bot aiogram

# Install broker connectors
pip3 install paramiko oandapyV20

# Verify
python3 -c "import ccxt, pandas, sklearn; print('✅ Core packages OK')"
```

### Step 4: Configure API Keys
```bash
# Create .env file
cat > .env << 'ENVEOF'
# Exchange API Keys
BYBIT_API_KEY=your_testnet_key
BYBIT_API_SECRET=your_testnet_secret

# Gate.io (if using)
GATEIO_API_KEY=your_key
GATEIO_API_SECRET=your_secret

# Mode
ENABLE_LIVE=false
TRADING_MODE=testnet

# Telegram (optional)
TELEGRAM_TOKEN=your_bot_token
TELEGRAM_ADMIN_CHAT=your_chat_id
ENVEOF
```

### Step 5: Test Run
```bash

python3 ULTIMATE_ORCHESTRATOR.py --mode testnet
```

### Step 6: Deploy with Screen/Tmux
